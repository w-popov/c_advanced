##### Курсовая работа 2. Численные методы. Программа вычисления площади фигуры, ограниченной пересечением графиков функций.
Язык: C (c11).
Нахождение корней - метод деления отрезка пополам.
Нахождение интеграла - метод трапеций.

##### Склонировать каталог
* Создать где-то каталог, зайти в него, открыть в нем терминал.
* Ввести в терминале: 
```Bash
git clone --no-checkout https://github.com/w-popov/c_advanced.git

cd c_advanced/
git sparse-checkout set CWNumericalMethods
git checkout
cd CWNumericalMethods/
```
